# 레벨업 잉글리시 (Level Up English)

> **초등학교 5~6학년을 위한 친근하고 재미있는 기초 영어 단어·문장 학습 및 퀴즈 웹앱**

아이들이 영어를 처음부터 부담 없이 배울 수 있도록 쉬운 한국어 설명, 상황별 꿀팁, 원어민 발음 듣기, 즉각적인 해설이 포함된 퀴즈, 그리고 정답 만점 시 신나는 아이 음성("와~!")과 빵빠레 효과음을 제공하는 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **4대 필수 생활 주제 (총 80개 콘텐츠)**
   - **일상생활 (Daily Life)**: 단어 10개, 문장 5개, 주요 표현 5개
   - **학교 생활 (School Life)**: 단어 10개, 문장 5개, 주요 표현 5개
   - **가족과 친구 (Family & Friends)**: 단어 10개, 문장 5개, 주요 표현 5개
   - **음식과 식사 (Food & Dining)**: 단어 10개, 문장 5개, 주요 표현 5개
   - 모든 단어에 발음 표기, 한글 뜻, 쉬운 예문과 해석 수록
   - 모든 문장과 표현에 자연스러운 한글 뜻과 '언제 사용하는지' 상황별 꿀팁 제공

2. **오늘의 5분 학습 (Daily Mission)**
   - 하루에 5개씩 소화할 수 있는 적정량 추천
   - 일일 목표 달성도 시각화 및 완료 시 축하 피드백

3. **원어민 발음 듣기 & 속도 조절**
   - Web Speech API 기반 원어민 발음 지원
   - 초보자를 위한 보통 속도(1.0x) 및 천천히 듣기(0.7x 🐢) 모드

4. **3가지 유형의 인터랙티브 퀴즈**
   - **뜻 맞히기 퀴즈**: 영어 단어/문장의 올바른 의미 찾기
   - **빈칸 채우기 퀴즈**: 문맥에 맞는 핵심 표현 완성하기
   - **듣고 고르기 퀴즈**: 원어민 발음을 듣고 알맞은 표현 고르기
   - 오답 시 즉각적인 쉬운 해설 제공
   - **틀린 문제 다시 풀기 (오답 노트)** 기능

5. **정답 만점 달성 축하 효과**
   - 100% 만점 시 아이의 환호 음성("와~!")과 트럼펫 빵빠레 울림
   - 화려한 컨페티(꽃가루) 효과 및 다시 듣기 버튼 제공

6. **로컬 데이터 저장 (localStorage)**
   - 학습 진도율, 연속 출석 일수(스트릭), 찜한 단어장, 오답 노트, 최근 퀴즈 기록을 기기에 안전하게 보관

7. **모바일 & PC 완벽 반응형 UI**
   - 컴퓨터와 스마트폰 화면 모두에 최적화된 반응형 레이아웃 및 모바일 하단 탭 내비게이션

## 🚀 기술 스택

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Audio & Sound**: Web Speech API, Web Audio API (Synthesized Brass Fanfare & Child Vocal Formants)
- **Effects**: Canvas Confetti

## 🛠 실행 방법

### 설치
```bash
npm install
```

### 로컬 개발 서버 실행
```bash
npm run dev
```

기본 브라우저에서 `http://localhost:3000`으로 접속하여 학습을 시작할 수 있습니다.

### 프로덕션 빌드
```bash
npm run build
```
